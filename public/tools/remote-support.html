Remote Support 🔒 you stay in control

Start a temporary support session and read the one-time code to your support agent. They can only join after you approve. You decide when to share your screen, you must separately approve remote control, and you can stop everything instantly. Nothing runs in the background and no access is kept after the session ends.

Support agent connected.

Start a support session

Only start a session if you are currently talking to a support agent you trust. You set a password now; your agent will need the one-time code and this password to join.

Join an existing session

To join you need two things from the person who started the session: their one-time code and the password they set. The customer still has to approve you before you can see anything.

You'll be taken to the join screen to enter the password and connect. No code yet? Ask the other person to press Start support session first.

What happens next: you receive a code, give your agent the code and password, they request to join, and you get a prompt to approve. You can refuse at any step, and closing this tab ends everything.

Windows blocks the file or shows a warning?
This is just because the file is new and unsigned — it is safe. After downloading:
  1. Open the downloaded RemoteSupportHelper.zip and drag RemoteSupportHelper.exe out to your Desktop.
  2. Double-click it. If Windows shows a blue SmartScreen box, click More info → Run anyway.

You stay in control: the agent can only move things while you allow it, and closing the helper window stops it instantly.
